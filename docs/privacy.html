Privacy Policy

Last updated: 16 November 2026

GoodFood Shorts Bot ("the app") is a personal automation tool operated by the owner of the GoodFoodGoodMood YouTube channel. It is used only with the owner's own Google account.

Data the app accesses

With the owner's permission, the app uses the YouTube Data API to read basic details of the owner's channel (name and handle, to confirm the right channel), upload videos, upload caption tracks and add videos to the owner's playlists.

How data is used and stored

The data is used only to publish the owner's own videos. The OAuth token is stored as an encrypted secret in the owner's private GitHub repository. No data is sold, shared with third parties, or used for advertising.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time from myaccount.google.com/permissions.

Contact

Questions: contact the channel owner through the YouTube channel's About page.
