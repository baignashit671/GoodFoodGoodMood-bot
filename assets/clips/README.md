# Your own cooking clips (optional, recommended)

Put your own short phone clips here (`.mp4`, `.mov`, `.mkv`, `.webm`). Vertical 9:16 is best.
Name each file with the keywords of what it shows, separated by `-` or `_`:

    onion-frying-pan.mp4
    tadka-jeera-ghee.mp4
    masala-chai-pour-cup.mp4
    paneer-cubes-cutting.mp4
    roti-tawa-puffing.mp4

For every scene the bot compares these keywords with the scene and the dish name and uses
the best-matching clip FIRST (before any stock or AI visual). A clip is used at most once per Short.

Your own footage is the strongest protection against YouTube's "reused content" rule.
Keep each file small (under ~50 MB) - GitHub blocks files over 100 MB.
